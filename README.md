# personal-portfolio

My personal portfolio site: a static home page and a page per project, with a light mission-control theme, built with [Astro](https://astro.build). No UI framework, just Astro components, plain CSS and a little TypeScript.

## Running it

Requires Node 22.12+.

```sh
npm install
npm run dev      # dev server at http://localhost:4321
npm run build    # static site in ./dist
npm run preview  # serve the production build
npm run check    # type-check the code (the dev server and build skip types)
npm run art      # re-render the brand art (needs the licensed font, not in the repo)
npm run media    # posters (first frames) for the projects' clips (needs ffmpeg)
npm run slides <slug> deck.pptx   # a project's slide images and PDF from its deck (needs PowerPoint, ffmpeg)
```

## Where things are

```
src/
  content/                all the copy: edit these to change what the site says
    site.ts               name, tagline, availability, resume and profile links
    about.md              About text and its opening statement
    clip.md               the climbing clip card in About
    projects/<slug>/      one folder per project: index.md, and its files in assets/
  content.config.ts       schemas for the projects and the clip
  components/             the pages' sections and cards (project/: the project page's parts)
  pages/index.astro       the home page
  pages/projects/[id].astro  each project's page
  pages/404.astro         the page for an address with nothing at it
  scripts/                client-side code (the rocket flights, the arcade, the theater and video
                          player, the live footer readouts) and the build-time project file helpers
  styles/global.css       design tokens and shared classes
  assets/brand/           generated by `npm run art`; don't edit by hand
public/assets/            icons, plus status.json (written by the server; not in the repo)
public/files/             files copied to the server by hand, not in the repo: resume(s), the About clip
scripts/new-project.mjs   `npm run new-project "Title"`: a new project folder from the template
scripts/render-art.py     `npm run art`: the display-font images (wordmark, headings, titles, icons)
scripts/media.mjs         `npm run media`: a poster beside each project clip (its first frame)
scripts/slides.mjs        `npm run slides`: a deck's slides (moving ones as clips) and its PDF
scripts/rebuild.sh        server: writes status.json at boot, then rebuilds the site
```

## Editing content

**About text:** conventions for the statement, prompts and links are at the top of `src/components/About.astro`.

**Adding a project:** every field, its options and the write-up's syntax are in [`src/content/projects/guide.md`](src/content/projects/guide.md); the project files themselves carry no comments.

1. Run `npm run new-project "Title"`. It makes `src/content/projects/<slug>/` with an `index.md` of every field, an empty `assets/` folder and the title art. The project starts as a draft: it shows under `npm run dev` at `/projects/<slug>/`, with any missing file marked on the page, and stays off the built site.
2. Put the project's images, clips, slides and PDFs in `assets/`; fields name them relative to it (`demo.mp4`, `slides/`). Clips and videos are committed, so compress them first (a short loop should be well under 1 MB), then run `npm run media` and commit the `.poster.webp` it makes beside each one.
3. For a slide deck, put the `.pptx` in `assets/` and run `npm run slides <slug> deck.pptx`: it exports every slide through PowerPoint into `assets/slides/` and the deck's PDF beside it (from WSL on the Windows machine with Office; it works on a copy, so the deck can stay open). A slide with a GIF or video becomes a clip, unless it would be over 12 MB.
4. Fill in `index.md`: `highlights` picks what Media shows (in that order, the first large) and `screen` what the top card plays; `achievement` and `statement` are the line leading into Media.
5. Delete `draft: true` and run `npm run build`. Once published, a missing file stops the build and names it.

Renamed a project? Rename its folder too (it's the page's address), then run `npm run art` to redraw its title.
