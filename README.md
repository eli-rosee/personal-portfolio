# personal-portfolio

My personal portfolio site: a single static page with a light mission-control theme, built with [Astro](https://astro.build). No UI framework, just Astro components, plain CSS and a little TypeScript.

## Running it

Requires Node 22.12+.

```sh
npm install
npm run dev      # dev server at http://localhost:4321
npm run build    # static site in ./dist
npm run preview  # serve the production build
npm run art      # re-render the brand art (needs the licensed font, not in the repo)
```

## Where things are

```
src/
  content/                all the copy: edit these to change what the site says
    site.ts               name, tagline, availability, resume and profile links
    about.md              About text and its opening statement
    clip.md               the climbing clip card in About
    projects/*.md         one file per project
  content.config.ts       schemas for the projects and the clip
  components/             the page's sections and cards
  pages/index.astro       the page itself
  scripts/                client-side code: the rocket launch, the live footer readouts
  styles/global.css       design tokens and shared classes
  assets/
    projects/             images for the project cards
    brand/                generated by `npm run art`; don't edit by hand
public/assets/            icons, plus status.json (written by the server; not in the repo)
public/files/             files copied to the server by hand, not in the repo: resume(s), the About clip
scripts/rebuild.sh        server: writes status.json at boot, then rebuilds the site
```

## Editing content

**About text:** conventions for the statement, prompts and links are at the top of `src/components/About.astro`.

**Adding a project:** run `npm run new-project "Title"`. It makes `src/content/projects/<slug>/index.md`, with every field written out and explained, and an `assets/` folder for the project's images, clips, slides and PDFs (paths in the file are relative to it). The project starts as a draft: it shows under `npm run dev` at `/projects/<slug>/`, with any missing file marked on the page, and stays off the built site until `draft: true` is deleted. Once published, a missing file stops the build and names it. Videos (`.mp4`, `.webm`, `.mov`) stay out of git and are copied to the server by hand. Run `npm run art` after renaming a project, to redraw its title.
